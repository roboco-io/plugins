# Evolve

무엇을 해봤고, 그 결과 Why/What/Not 중 어느 줄이 어떻게 바뀌어야 하는지 적어주세요.
배운 내용 자체는 INTENT.md에 쌓지 않습니다. 의도를 고쳐 쓰고, 이유는 커밋 메시지에 남깁니다.

```
탐구: [무엇을 했는가 — 프로토타입, 인터뷰, 경쟁사 조사, 사용자 테스트 등]

결과: [무엇을 알게 되었는가]

바뀌는 의도:
- Why: [고쳐 쓸 줄 — 없으면 "변경 없음"]
- What: [추가/삭제/수정할 항목 — 없으면 "변경 없음"]
- Not: [새로 생긴 경계, 풀린 경계 — 없으면 "변경 없음"]

상태: [유지 | exploring | clarified | dropped]
```

세 섹션 모두 "변경 없음"이면 이 결과는 아직 의도에 영향을 주지 않는 것입니다. INTENT.md를 수정하지 않습니다.
